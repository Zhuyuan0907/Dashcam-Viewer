這個應用程式提供什麼功能？

上傳與旅程整理

透過瀏覽器或站台啟用的 SFTP 上傳影片，自動依拍攝時間整理旅程並合併前後鏡頭素材。

播放、剪輯與分享

同步觀看雙鏡頭、選取區間匯出片段，或由你建立限時分享連結，讓持有連結的人查看指定旅程。

YouTube 排程備份

連結自己的頻道，選擇旅程、鏡頭、標題與可見性，立即上傳或排程；傳輸在伺服器背景執行。

為什麼需要 Google／YouTube 授權？

本站使用 YouTube API Services。Google 授權只在你選擇連結頻道時發起，用來上傳你指定的影片、讀取頻道與影片處理狀態，並在你選擇雙鏡頭上傳時建立播放清單、加入兩部影片及在影片說明附上配對連結。

本站保存加密的授權憑證，讓排程在你關閉瀏覽器後仍能執行；也會保存頻道名稱、影片 ID、上傳紀錄與狀態快照。你可以暫停、取消或解除連結。本站帳號登入與 Google 頻道授權是各自獨立的流程。

影片只會在你選擇並確認後傳送到 YouTube。本機原檔只有在你另外確認清理、且系統核對上傳完成後才會刪除。YouTube 會重新壓縮影片，重要原檔請另行保留。
