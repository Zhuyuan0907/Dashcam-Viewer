    YouTube 管理

    授權設定、頻道、上傳進度、已上傳影片與釋放本機空間。要上傳新影片請到 上傳到 YouTube。

    1. 建立 Google Cloud 專案
      開啟 Google Cloud 建立專案，名稱隨意（例如「行車記錄」），按「建立」。之後的步驟都確認左上角選的是這個專案。
    2. 啟用 YouTube Data API v3
      開啟 YouTube Data API v3，按「啟用」。
    3. 設定 OAuth 同意畫面
      開啟 Google Auth Platform，按「開始」：
      • 應用程式名稱填「行車記錄」，使用者支援電子郵件選你的 Gmail
      • 目標對象選 外部，聯絡資訊填你的 Gmail，同意政策後建立
      • 到左側「目標對象」→「測試使用者」→ 新增 你要連結的 Gmail（沒加會出現 403 access_denied）
    4. 建立 OAuth 用戶端
      開啟 用戶端 → 建立用戶端：
      • 應用程式類型：網頁應用程式
      • 已授權的 JavaScript 來源：
      • 已授權的重新導向 URI：（點一下複製，必須完全一致）
      建立後會顯示「用戶端 ID」與「用戶端密鑰」，複製到下一步。
    5. 貼上並儲存
      密鑰加密保存，不會再顯示在瀏覽器。
    連結時看到「Google 尚未驗證這個應用程式」？

    這是自己建立、還沒送審的專案的正常畫面：點「繼續」（或「進階」→「前往行車記錄」）即可。另外兩個限制請知悉：

    ・專案維持「測試」狀態時，授權約 7 天會失效，需要回來重新授權；到 Google Auth Platform「目標對象」按「發布應用程式」可延長。
    ・未經 Google 稽核的 API 專案，上傳的影片會被 YouTube 鎖成「私人」，選「不公開／公開」也一樣，直到專案通過稽核。

    前後鏡頭都上傳並由 YouTube 處理完成的旅程才能勾選。有匯出片段或裁剪備份的旅程會被略過。
