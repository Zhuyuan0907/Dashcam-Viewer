隱私權政策 / Privacy Policy

生效及更新日期：2026-10-08

本政策適用於「{{SITE_TITLE}}」（使用 Dashcam Viewer 程式提供的行車影片管理服務，以下稱「本站」），涵蓋本站帳號、影片管理、分享，以及 Google／YouTube 授權與備份功能。本站由提供你帳號的站台營運者管理。隱私、資料存取、更正或刪除請求的公開聯絡方式：{{PUBLIC_CONTACT}}

Dashcam Viewer manages dashcam footage and backs up videos selected by the user to their own YouTube channel. This policy explains the account information, footage, Google OAuth credentials and YouTube API data we collect; their purposes, recipients, storage, retention, security, and deletion. Google authorization is optional. We do not sell Google user data, use it for advertising, or use it to train AI models.

2. 使用目的與資料使用限制 / Use of data

本站僅將上述資料用於你可見的影片管理、帳號設定、分享、排程備份、狀態同步及維運安全功能。影片不會因登入或連結 Google 就自動傳送至 YouTube；你必須選擇旅程、上傳設定並確認工作。分享與本機清理也需另外操作。

本站不出售 Google 使用者資料，不將 Google 或 YouTube 資料用於廣告、跨服務追蹤、信用評分，或訓練人工智慧／機器學習模型。本站對從 Google APIs 取得資訊的使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。對 Google 使用者資料的人工存取限於你的明確同意、必要的安全調查或適用法律要求。

3. Google／YouTube 授權範圍 / OAuth permissions

本站使用 YouTube API Services。Google 授權是選用功能；拒絕或撤銷授權會停用 YouTube 操作，你仍可使用本站的本機影片管理功能。

  • https://www.googleapis.com/auth/youtube.upload：將你確認的影片及標題、說明、可見性和兒童內容設定上傳至自己的頻道。
  • https://www.googleapis.com/auth/youtube.force-ssl：讀取頻道及本站上傳影片的狀態；雙鏡頭上傳時建立該趟播放清單、加入影片，並更新本站上傳影片的說明以附上配對連結。Google 同意畫面對此權限可能有較廣的管理描述，本站實際用途限於上述操作。

本站不透過此功能修改或刪除其他影片，也不透過 API 刪除 YouTube 影片。Google 對資料的處理請見 Google 隱私權政策；使用 YouTube 功能也受 YouTube 服務條款規範。

4. 資料會提供給誰 / Sharing and recipients

  • Google／YouTube：上傳時傳送你選定的影片、標題、說明、可見性與兒童內容設定；憑證僅用於 Google OAuth 與 YouTube API 授權請求。Google 依自身政策處理資料。
  • 站台營運者：具有伺服器、資料庫與備份管理權限，用於提供服務、處理你的請求及必要安全維運。一般使用者只能透過 YouTube 功能查看自己的上傳紀錄。
  • 你選擇的觀看者：公開旅程可由站內有權存取的人查看；免登入分享連結可由持有者在有效期間觀看。YouTube 觀看範圍依你設定的可見性及平台規則決定。
  • 連線與頭像服務：主機及代理／CDN 業者處理連線所需的 IP 與請求資訊。若本站電子郵件或電子郵件形式的使用者名稱用來載入 Gravatar 頭像，瀏覽器會向 Gravatar 傳送該地址的雜湊及連線資訊，詳見 Automattic 隱私權政策。這不是 Google OAuth 讀取的電子郵件。
  • 法律及安全：僅於法律要求、處理濫用或保護安全的必要範圍提供資料；Google 資料轉移仍遵守 Limited Use 限制。

本站未提供廣告追蹤或將授權資料交給資料仲介的功能，也不向一般使用者輸出授權憑證或 YouTube 續傳網址。

5. 儲存、安全與保存期間 / Storage, security and retention

帳號、影片索引、工作紀錄與 Google 授權資料存於營運者管理的伺服器及 SQLite 資料庫；影片和剪輯檔案存於該站台的檔案空間，只有你選定並確認的影片另傳送到 YouTube。

Google OAuth Client Secret、access token、refresh token 及續傳資訊以 AES-256-GCM 加密，金鑰與資料庫分開保存。本站密碼使用加鹽雜湊，公開站台與 Google 授權使用 HTTPS，操作受到登入及權限檢查保護。這些措施降低風險，但不代表資料沒有遺失或外洩的可能。

  • 帳號與影片：於帳號與影片管理用途存續期間保存，直到你使用可用的刪除功能或提出刪除請求；過期登入工作階段由系統清理。
  • Google 授權與 YouTube 紀錄：於連結與備份用途存續期間保存；解除連結立即移除目前資料庫的授權與上傳紀錄。授權 state 有效期 10 分鐘且只能使用一次，系統在後續發起授權時清理過期 state。影片狀態於同步時更新並標示最近同步時間。
  • 失敗素材：隔離素材依設定輪替，程式預設保存 7 天；不包含已整理的原始旅程影片。
  • 備份：資料庫快照預設每 24 小時建立、保留最近 7 份，可由營運者調整。回退備份可能保存更久，並包含加密授權資料與金鑰；快照不等於影片備份。刪除請求可一併要求處理備份殘留。
  • 技術日誌：依主機與代理服務設定輪替，僅用於運作、安全與排查；可聯絡營運者確認實際保存設定。

6. 存取、更正、撤銷及刪除 / Access, revocation and deletion

  1. 更正本站資料：「我的帳號」可修改電子郵件、顯示名稱、裝置與偏好；其他存取、更正或帳號刪除請聯絡營運者。
  2. 停止 YouTube 操作：「維運 → YouTube 管理 → 頻道」可暫停或解除連結，工作可取消。解除連結立即刪除該使用者在目前資料庫的授權、影片連結、播放清單配對及上傳紀錄，並嘗試向 Google 撤銷。撤銷失敗時會提示你自行處理。
  3. 在 Google 撤銷：可隨時透過 Google 帳號第三方存取設定撤銷本站權限。之後本站無法以該授權執行新的有效 API 操作；移除本站紀錄請同時解除連結或通知營運者。
  4. 完整刪除請求：聯絡 {{PUBLIC_CONTACT}}，提供本站使用者名稱、資料範圍及是否包含帳號、影片或備份殘留。營運者會核對請求、說明處理方式並回覆結果。請勿提供密碼、Google token 或 Client Secret。

解除連結或刪除本站 YouTube 紀錄不會刪除本機或 YouTube 影片；YouTube 影片請在 YouTube Studio管理。本機清理是另行確認的永久刪除操作；本站不保證可從 YouTube 還原原始畫質。

本站另保留經雜湊的頻道額度計數以遵守上傳上限，不含授權憑證，解除連結後不再用於執行你的上傳。

7. Cookie 與瀏覽器儲存 / Cookies and browser storage

本站使用登入 Cookie 維持工作階段；localStorage／sessionStorage 保存主題、播放偏好、續看位置及介面快取，用於功能運作，不用於廣告。你可由瀏覽器清除，清除 Cookie 會登出，但不會刪除伺服器影片或 Google 授權。公開介紹與政策頁只載入本站樣式與主題程式，不需登入。
