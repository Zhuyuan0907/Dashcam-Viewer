YouTube 功能條款與隱私說明

更新日期：2026-10-06。此功能使用 YouTube API Services。使用本功能即表示你同意 YouTube 使用條款，Google 依其 隱私權政策 處理收到的資料。

授權與資料用途

登入本站仍使用本站帳號。連結 YouTube 時，Google 會取得你的同意並提供上傳、讀取頻道／影片狀態，以及管理播放清單與影片說明的 OAuth 授權。管理權限只用於：選擇「前後鏡頭都上傳」時，為每趟建立一個播放清單、加入該趟的兩部影片，並在這兩部影片的說明末尾附上彼此的連結；本站不會修改或刪除其他影片與播放清單。本站不取得你的 Google 密碼。本站使用加密保存的 access token、refresh token 執行你建立的背景上傳排程，讀取你的頻道名稱與 ID，確認影片處理狀態，並保存上傳影片 ID、標題、說明、時間、鏡頭配對、進度和操作紀錄。授權憑證及續傳網址不回傳至瀏覽器。

只有你能透過此功能查看自己的 YouTube 上傳紀錄。站台由部署者營運；部署者具伺服器與資料備份的管理權限。資料保存在此站台的資料庫，憑證以獨立金鑰加密。本站另外保留經雜湊的頻道額度計數以遵守上傳上限，不含授權憑證。你的選定影片、標題、說明、可見性和兒童內容設定會傳送至 YouTube；本站不另向其他服務傳送這些資料。本站使用登入 Cookie，並在瀏覽器保存既有的主題與帳號介面偏好。

控制與刪除

你可以暫停佇列、取消未完成的傳輸或解除帳號連結。解除連結會立即刪除本站目前資料庫的 YouTube 授權、雲端影片連結與上傳紀錄，並嘗試向 Google 撤銷授權；若 Google 暫時無法連線，畫面會提示你自行撤銷。你也可隨時在 Google 帳號第三方存取設定 撤銷授權。本機影片和已上傳至 YouTube 的影片不會因解除連結而刪除；YouTube 影片請在 YouTube Studio 自行管理。

資料庫自動快照依站台設定輪替（預設保留 7 份），維運與部署回退備份由部署者管理；如需一併移除備份中的授權資料，請聯絡提供本站帳號的站台管理員。你選定並確認清理本機旅程前，系統會確認所有現有鏡頭已成功上傳、YouTube 已處理完成及本機版本相同；有額外影片、匯出片段或裁剪原始備份時拒絕清理。清理會永久移除本機旅程檔案，並保留 YouTube 副本紀錄。

保存、額度與下載限制

YouTube 會轉碼影片，並可能因帳號、版權或平台規則移除影片；它不承諾作為永久或原畫質備份。重要素材請另行保留原檔。頻道的 24 小時上傳上限 依地區與頻道紀錄不同，沒有統一保證數值。API 專案目前預設每天 100 次上傳呼叫，所有使用者共用；Google Cloud Console 所示額度為準。未經審核的 API 專案 可能限制為私人影片。

本站提供本機原影片下載。清理本機後，請使用 YouTube Studio 或 Google Takeout 匯出。Studio 官方下載通常為 720p／360p；Takeout 依 Google 提供的格式匯出，無法保證原畫質。YouTube Data API 沒有原影片下載端點。本站不透過未公開介面抓取 YouTube 影音檔。
