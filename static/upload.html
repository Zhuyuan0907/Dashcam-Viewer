透過 SFTP 上傳行車記錄

建立一個臨時 SFTP 上傳工作階段,用 FileZilla 等工具把片段直接傳到專屬資料夾,完成後回此頁按「確認並處理」。

怎麼上傳?

本系統目前針對 MiVue™ MP20 前後雙鏡頭行車記錄器設計。它會把行車過程切成一段段短片, 本站會依「日期 / 趟次」自動整理、用 ffmpeg 無損合併成完整旅程供瀏覽。

檔案格式
  • 影片檔名格式:(FILE|EMER)YYMMDD-HHMMSS-序號(F|R).mp4。F=前鏡頭、R=後鏡頭;EMER=G-sensor 緊急鎖檔。
  • 每支影片通常伴隨一個同名 .NMEA 檔(GPS / G-force 軌跡),請一併上傳。
  • 可直接把記憶卡裡的原始片段整批拖入(結構不拘),或上傳已整理好的 YYYY-MM-DD/ 旅程資料夾。
上傳流程
  1. 按下方「建立上傳工作階段」,取得一組一次性 SFTP 連線資訊(使用者 / 密碼 / 伺服器)。
  2. 用 FileZilla / WinSCP / sftp 連線(最快:複製「FileZilla 指令」貼進終端機自動開啟),把上述檔案直接拖進去。
  3. 傳完回到此頁,按該工作階段的「確認並處理」。系統會自動依停留間隔切趟、無損合併前後鏡頭、解析 NMEA 的 G-force 事件。
  4. 處理完成後即可到「瀏覽旅程」觀看。閒置過久(未上傳)資料夾會自動清除失效。
