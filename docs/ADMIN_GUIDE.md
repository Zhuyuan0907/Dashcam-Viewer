## 角色與權限

| 角色 | 能做什麼 |
| --- | --- |
| **擁有者**（第一個透過 `/setup` 建立的帳號） | 全部權限；唯一能設定 YouTube 授權、建立或調整其他管理員 |
| **管理員** | 管理使用者、站台設定、維運頁；可看所有旅程 |
| **一般使用者** | 上傳、觀看與管理自己的旅程、片段、分享與 YouTube 上傳 |

- 旅程預設私人，只有擁有者本人與管理員看得到；使用者可個別公開。
- 管理員重設他人密碼時，會撤銷該帳號所有登入中的工作階段。
- `/admin`、`/ops` 由伺服器端驗證管理員身分，未登入會導回登入頁。

## 管理頁

導覽列「管理」：

| 分頁 | 內容 |
| --- | --- |
| **使用者** | 新增帳號、角色、上傳時限、重設密碼 |
| **儲存與上傳** | 資料碟使用量、檢視檔案、目前進行中的上傳 |
| **外觀與品牌** | 網站標題、頁尾文字、登入頁標語與背景、站台 icon、favicon、語言與單位 |
| **行為與上傳設定** | 切趟間隔（預設 15 分鐘）、上傳閒置時限、SFTP 顯示的主機／埠 |
| **檢舉輔助** | 預設檢舉網站網址與名稱（只接受 http/https） |

設定分頁的變更要按右上角「儲存設定」。介面文字可直接編輯資料夾中的 `strings.yml`，重啟服務後生效。

## 維運頁

導覽列「維運」：

| 分頁 | 用途 |
| --- | --- |
| **事件與善後** | 影片整理失敗時的紀錄。點一筆可看原因與修復動作：重新合併、容錯重合（略過壞片段）、丟棄素材、標記已處理。失敗素材隔離保留（預設 7 天）後自動清除 |
| **健康檢查與工具** | 掃出缺影片或 0 位元組的旅程；檢查 Node、FFmpeg、權限與空間；從磁碟 `info.json` 重建資料庫（不動影片） |
| **儲存空間** | 見下一節 |
| **YouTube 管理** | 授權設定、頻道、上傳進度、已上傳與清理 |
| **資料庫檢視** | 唯讀瀏覽各資料表，密碼與憑證自動遮蔽 |

## 儲存空間與回收

「維運 › 儲存空間」上方顯示資料碟用量（旅程影片／其他資料／可用）與可直接回收的空間。
下方列出**佔空間但瀏覽頁看不到**的檔案：

| 類型 | 說明 | 可刪除 |
| --- | --- | --- |
| 已被合併取代的來源旅程 | 幾趟被合併成一趟後，原本的來源旅程已隱藏但影片仍在 | ✅（合併旅程影片存在時） |
| 中斷合併的半成品 | 舊版本合併途中服務中斷留下的不完整資料夾 | ✅（超過一小時未變動） |
| 未登錄的旅程 | 有 `info.json` 但資料庫沒有紀錄 | ❌ 請用「從磁碟重建」救回 |

勾選後按「刪除勾選項目」，會再確認一次。伺服器會重新掃描並逐項驗證，不信任畫面上的資料。

**最大宗的空間是旅程影片本身。** 釋放的方式是上傳到 YouTube，確認處理完成後在
「YouTube 管理 › 已上傳與清理」刪除本機檔案。

> 整理新影片時，伺服器需要和影片差不多大的暫存空間。硬碟接近滿時，大批上傳可能整理失敗，
> 建議保留至少一次上傳量的可用空間。

## YouTube 授權設定

只需要擁有者做一次，約 10 分鐘，需要一個 Google 帳號，不用付費。
在「維運 › YouTube 管理 › ① 授權設定」有同樣的步驟與可一鍵複製的網址。

1. **建立 Google Cloud 專案**：開啟 [Google Cloud 建立專案](https://console.cloud.google.com/projectcreate)，
   名稱隨意（例如「行車記錄」）。之後的步驟都要確認左上角選的是這個專案。
2. **啟用 API**：開啟 [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com)，按「啟用」。
3. **設定 OAuth 同意畫面**：開啟 [Google Auth Platform](https://console.cloud.google.com/auth/overview) →「開始」：
   - 應用程式名稱填「行車記錄」，支援電子郵件選你的 Gmail。
   - 目標對象選**外部**，聯絡資訊填你的 Gmail，同意政策後建立。
   - 左側「目標對象」→「測試使用者」→ 新增**要連結 YouTube 的每個 Gmail**（沒加會出現 403 access_denied）。
4. **建立 OAuth 用戶端**：開啟 [用戶端](https://console.cloud.google.com/auth/clients) → 建立用戶端：
   - 應用程式類型：**網頁應用程式**
   - 已授權的 JavaScript 來源：你的網站網址，例如 `https://dashcam.example.com`
   - 已授權的重新導向 URI：`https://你的網址/api/youtube/callback`（必須完全一致）
5. **貼上並儲存**：把「用戶端 ID」與「用戶端密鑰」貼到授權設定頁，按「儲存設定」。
   密鑰以 `DATA_DIR/youtube.key` 加密後存於資料庫，之後不會再顯示。

完成後，使用者就能在「上傳到 YouTube」第 1 步連結自己的頻道。

### 須知

- **測試模式的授權約 7 天失效**：到 Google Auth Platform「目標對象」按「發布應用程式」可延長；
  自建未送審的專案在授權時會看到「Google 尚未驗證這個應用程式」，點「繼續」即可。
- **未經 Google 稽核的 API 專案，上傳的影片會被鎖成私人**，選「不公開／公開」也一樣，直到通過稽核。
- 授權範圍：`youtube.upload`（上傳）與 `youtube.force-ssl`（建立前後鏡頭播放清單、在說明附上連結、讀取狀態）。
  本站不會刪除或修改其他影片。
- API 專案每日額度所有使用者共用，以 Google Cloud Console 顯示為準；超過時會自動延到隔天。
- 完整備份必須包含 `youtube.key`，只有資料庫快照無法解密授權。

## YouTube 管理

「維運 › YouTube 管理」：

- **頻道**：目前連結的頻道、過去 24 小時用量、每日上傳上限、暫停／繼續佇列、重新授權、解除連結。
  解除連結會刪除本站的授權與上傳紀錄，本機與 YouTube 上的影片都會保留。
- **上傳進度**：所有工作的狀態與逐步紀錄。可「重試／續傳」、「從頭重新上傳」（續傳工作階段過期時，
  先到 Studio 確認沒有重複影片）或取消。
- **已上傳與清理**：
  - 打開時自動與 YouTube 同步（最多每 5 分鐘一次），或按「立即同步」：讀回 YouTube 上目前的標題、可見性、
    觀看／按讚／留言數，並標出已在 YouTube 刪除的影片。同步只讀取。
  - 「在 Studio 編輯」直接開啟該影片的 YouTube Studio 頁面，刪除或修改都在那裡做。
  - 「前後鏡頭清單」開啟該趟的播放清單；「下載原檔」下載本機原始畫質。
  - 勾選前後鏡頭都已處理完成的旅程 →「刪除勾選旅程的本機檔案」。有匯出片段或裁剪備份的旅程會被略過，
    需先在旅程頁處理。
