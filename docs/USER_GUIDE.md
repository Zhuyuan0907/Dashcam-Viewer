## 1. 開始使用

1. **登入**：帳號由管理員建立。第一次登入若被要求改密碼，請先設定新密碼。
2. **新增行車記錄器**：右上角頭像 →「個人設定」→「行車記錄器」→ 新增。選擇型號
   （MiVue、Polaroid 或「其他／自訂」），可填暱稱，例如「機車固定式」。
   一台設為預設，上傳時會自動帶入。
3. **導覽列**：首頁（最近一趟與騎乘日曆）、瀏覽旅程、片段、上傳、背景作業、YouTube。
   管理員另有「管理」與「維運」。

## 2. 上傳影片

### 用瀏覽器上傳（建議）

1. 進入「上傳」→「建立上傳工作階段」，確認來源記錄器。
2. 把記憶卡資料夾或影片**拖進頁面**（或點選選檔）。系統先檢查檔名，標示會整理成哪個鏡頭；
   格式不符或和所選記錄器不一致時會提示。
3. 預設「收齊後自動整理」，傳完就會交給背景處理；取消勾選則需手動按「確認並處理」。
4. 到「背景作業」看進度，完成後到「瀏覽旅程」觀看。

檔案以 4 MiB 分塊傳送並記住進度。中途關掉頁面，只要回到上傳頁、選回同一批檔案，
就會從已確認的位置續傳。

### 用 SFTP 上傳（大量檔案）

建立工作階段後可看到 SFTP 連線資訊（主機、埠、帳號、一次性密碼），可下載 FileZilla 站台設定。
**傳完並中斷 SFTP 連線後**，回到網頁按「確認並處理」。工作階段閒置太久會自動失效。

### 上傳後可以關閉瀏覽器嗎？

- **還在傳輸中：不可以**（關掉後可回來續傳，但不會自己完成）。
- **畫面顯示整批已接受處理後：可以**。整理在伺服器背景執行。

### 支援的影片格式

| 記錄器 | 檔名範例 | 鏡頭 |
| --- | --- | --- |
| MiVue MP20 | `FILE260912-103045-001F.mp4`（含 `EMER…`、`.NMEA`） | F 前／R 後 |
| Polaroid MS279WG | `2026_0912_103045_001A.TS` | A 前／B 後 |
| 通用格式（選「其他／自訂」） | `20260912_103045_F.mp4`、`20260912_103045_R_02.mov` | F 前／R 後 |
| 已整理旅程 | `YYYY-MM-DD/旅程資料夾/前鏡頭.mp4`、`後鏡頭.mp4` | 依檔名 |

- 拍攝時間取自檔名，不看上傳時間。
- 同一個工作階段不要混合不同廠牌的命名規則。
- 只有後鏡頭也可以匯入。
- 編碼、解析度或幀率不一致的片段會被要求分批或先轉檔。

### 整理規則

相鄰片段間隔超過設定的時間（預設 15 分鐘）就視為新的一趟。合併是**無損串接**，
不重新壓縮，畫質與原檔相同。整理失敗時原始素材會被隔離保留，由管理員重試，不會遺失。

## 3. 瀏覽與觀看旅程

### 找旅程

- **瀏覽旅程**：左側依日期列出，右側是當天的旅程卡片。
- **時光機**：瀏覽頁右上角，以堆疊視窗前後翻日期，觸控板／拖曳／方向鍵都能操作。
- **首頁**：最近一趟、騎乘日曆熱圖（點格子跳到該日）、隨機回顧。

### 播放器

前鏡頭為主畫面、後鏡頭為子母畫面，可切換主鏡頭。兩個鏡頭會同步等待緩衝，
不會一支在播、一支停住。

| 操作 | 方式 |
| --- | --- |
| 播放／暫停 | 空白鍵或 K |
| 後退／前進 5 秒 | ← / → |
| 後退／前進 10 秒 | J / L |
| 逐格 | , / . |
| 截圖 | S |
| 全螢幕 | F |
| 靜音 | M |
| 縮放／平移／還原 | 滾輪縮放、拖曳平移、雙擊還原 |
| 播放速度、子母畫面 | 控制列右側「設定」齒輪 |

- **續看**：看到一半離開，下次打開會從上次的位置繼續（看完會清除）。
- **深連結**：網址加 `#t=秒數` 可直接跳到該時間點。
- **備註**：旅程頁可新增文字備註。

## 4. 剪輯與片段

在旅程頁按「剪輯」開啟時間軸，拖曳入點／出點把手（或按 I / O）選取範圍。同一個選取可以：

### 匯出片段（不影響原旅程）

- 選擇鏡頭：前鏡頭、後鏡頭，或子母畫面合成。
- **精確模式**：重新編碼，起訖準確。
- **快速模式**：無損，速度快，但頭尾可能多帶幾秒（從最近的關鍵影格起算）。
- 匯出在背景執行，關掉頁面也會完成。成品在「片段」頁，可播放、改名、下載、刪除。

### 整趟裁剪（會永久縮短整趟）

把整趟縮短成選取區間，前後鏡頭一起處理。系統會保留原始備份，可以從旅程頁還原。
同一趟同時只能進行一個裁剪。

---

## 5. 分享與公開

- **快速分享（免登入）**：旅程頁「快速分享」產生限時連結（1、7 或 30 天），
  對方不用帳號就能看前後鏡頭，可隨時撤銷或重新產生。
- **公開給站內使用者**：旅程頁「可見性」可單趟設為公開；個人設定可改預設值。
  旅程預設**私人**，只有你和管理員看得到。

## 6. 檢舉輔助

在「片段」頁的片段卡上按「⚑ 檢舉」：

1. 系統依旅程時間自動換算**違規時間**。
2. 填車牌、地點（會記住上次）、違規事實與描述。
3. **複製檢舉文字**，下載片段，再開啟所在縣市的檢舉網站貼上。
4. 送出後按「標記已檢舉」，片段卡會顯示徽章。

各縣市檢舉系統沒有公開 API 且有驗證碼，所以本站只準備資料、不代為送出。
多數單位要求未經剪輯的原始畫面，建議用「前鏡頭＋快速模式」匯出。

## 7. 備份到 YouTube

把旅程上傳到自己的 YouTube 頻道當備份，確認成功後可刪除本機檔案、釋放硬碟空間。

> 第一次使用前，站台擁有者要先完成一次性的 Google 授權設定（[管理員手冊](ADMIN_GUIDE.md#youtube-授權設定)）。
> 還沒設定時，精靈第 1 步會說明並提供設定連結。

### 上傳精靈（導覽列「YouTube」）

1. **連結頻道**：勾選同意條款 →「使用 Google 帳號連結」→ 在 Google 頁面授權。
   若看到「Google 尚未驗證這個應用程式」，點「繼續」即可（自建專案的正常畫面）。
2. **選擇影片**：預設「待上傳」只列出仍有可上傳鏡頭的旅程；可切換「佇列中」、
   「已上傳」或「全部」查看紀錄，並按連結開啟 YouTube 影片或旅程預覽。
   可整趟勾選，也可單獨選前／後鏡頭；已上傳或已排隊的鏡頭不能重複選。
   **已選清單**會保留跨頁、跨日期的選擇，列出每趟實際選到的鏡頭與影片數，並可逐趟移除。
   手機可點「已選清單」展開；更改鏡頭篩選會移除不符合的已選影片並提示。
3. **標題與說明**：每部影片自動填入自己的資料。可插入的標籤：`{date}` 日期、`{time}` 開始時間、
   `{end_time}` 結束時間、`{camera}` 鏡頭、`{trip_no}` 當日趟次、`{trip_id}` 旅程編號、
   `{device}` 裝置、`{duration}` 片長、`{filename}` 檔名。右側即時預覽。
4. **上傳方式**：
   - 可見性：私人（建議）／不公開／公開。進階設定可排程開始時間。
   - 鏡頭已在第 2 步選好；使用前後鏡頭模式時，兩部都處理完成後會自動配成播放清單。
5. **確認送出**：檢查每趟的鏡頭清單、實際影片數、可見性與開始時間後，勾選確認並按
   「加入上傳佇列」。送出前會重新檢查狀態；已排隊或內容變更的影片會移出清單供重新確認。
   若佇列已暫停，送出只會排隊，不會自動恢復。佇列運作時會在背景依序上傳，
   每 24 小時有建立上傳的嘗試上限，失敗也計入，關掉瀏覽器仍會繼續。

### 進度、同步與清理（管理員：維運 › YouTube 管理）

- **上傳進度**：每部影片的狀態、百分比與逐步紀錄；可重試、續傳或取消。
- **已上傳與清理**：
  - 打開時會自動**與 YouTube 同步**（也可按「立即同步」），顯示 YouTube 上目前的
    標題、可見性、觀看／按讚／留言數。同步只讀取，不會改動 YouTube。
  - 要**刪除影片、改標題或改可見性**：按「在 Studio 編輯」到 YouTube Studio 操作，回來再同步。
  - 在 YouTube 被刪除的影片會標出「找不到」，可回到精靈重新選取上傳。
  - **釋放本機空間**：勾選前後鏡頭都已上傳並處理完成的旅程 →「刪除勾選旅程的本機檔案」。
    系統會再向 YouTube 確認一次才刪除。

> YouTube 會重新壓縮影片，也不保證永久保存或能下載回原畫質。真正重要的原始檔請另外備份。
> 未經 Google 審核的 API 專案，上傳的影片會被 YouTube 鎖成「私人」。

## 8. 背景作業

「背景作業」列出整理、裁剪、匯出等工作：排隊中、執行中、完成、部分成功、失敗。
點一筆可看逐步紀錄，可取消或重試。服務重啟時正在進行的工作會標示「中斷」，需要手動重試。

---

## 9. 個人設定

右上角頭像 →「個人設定」：

- **個人資料**：顯示名稱、Email（用於 Gravatar 頭像）。
- **帳號與密碼**：修改密碼。
- **看片與外觀**：預設主鏡頭、播放速度、旅程預設是否公開、介面主題（港灣／陶土／暮山）。
- **行車記錄器**：新增、編輯、設定預設裝置。

## 10. 常見問題

**上傳後找不到旅程？**
到「背景作業」看處理是否完成或失敗。失敗時素材會被隔離保留，請管理員到「維運 › 事件與善後」重試。

**影片在瀏覽器無法播放？**
部分 HEVC（H.265）來源是否能播放取決於瀏覽器與裝置，本站不會自動轉檔。可改用支援 HEVC 的瀏覽器。

**網路慢時一直停頓？**
兩個鏡頭會一起等待緩衝。本站播放原始畫質，目前沒有自動降畫質。

**快速匯出的片段頭尾多了幾秒？**
快速模式為無損，只能從關鍵影格起算。需要精準起訖請用精確模式。

**連結 YouTube 時出現 403 access_denied？**
Google 專案還在測試模式，且你的 Gmail 沒有加入「測試使用者」。請管理員依
[YouTube 授權設定](ADMIN_GUIDE.md#youtube-授權設定) 第 3 步加入。

**YouTube 授權過幾天就失效？**
Google 專案維持「測試」狀態時，授權約 7 天會過期。回到精靈第 1 步重新授權，或請管理員發布應用程式。
